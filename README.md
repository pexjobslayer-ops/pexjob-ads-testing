# META ADS TESTING AI V3.0 — สกิลสำหรับ Claude

ระบบ Media Buyer อัตโนมัติสำหรับโฆษณา Meta (Facebook/Instagram):
**ดึงข้อมูล → วิเคราะห์ → วินิจฉัย → ปรับปรุง → สเกล → รายงานรายวัน 09:00 น.**

บอกทันทีว่าแอดไหนทำเงิน แอดไหนขาดทุน แอดไหนควรปรับ โคลน หรือหยุด

## วิธีติดตั้ง (ง่ายสุด)

คัดลอกข้อความนี้ไปวางในแชต Claude:

```
ติดตั้งสกิลจาก https://github.com/pexjobslayer-ops/pexjob-ads-testing ให้หน่อย
```

Claude จะอ่านสกิลแล้วแสดงการ์ด — กด **บันทึก** ก็ใช้ได้ทันที

## วิธีสำรอง: อัปโหลด ZIP

1. กด **Code → Download ZIP** ที่หน้านี้ แล้วแตกไฟล์
2. บีบอัดเฉพาะโฟลเดอร์ `meta-ads-testing-ai` เป็น ZIP (ข้างในต้องมี `SKILL.md`)
3. ใน Claude ไปที่ **Customize → Skills** → **Upload skill** → เลือกไฟล์ ZIP
4. เปิดสวิตช์สกิล

## ติดตั้งใน Claude Code

```bash
git clone https://github.com/pexjobslayer-ops/pexjob-ads-testing
cp -r pexjob-ads-testing/meta-ads-testing-ai ~/.claude/skills/
```

## ก่อนใช้งาน

- เชื่อม **Meta Ads** connector ใน Claude (Settings → Connectors)
- (ไม่บังคับ) เชื่อม **Gmail** หากต้องการรับรายงานทางอีเมล
- ลองพิมพ์ "วิเคราะห์แอดเมื่อวาน" หรือ "ตั้งรายงานแอดรายวัน 9 โมง" — ครั้งแรกสกิลจะถามบัญชีโฆษณา ชื่อสินค้า ราคาขาย และต้นทุน

## หมายเหตุ

- ใช้ข้อมูลจริงจากบัญชีเท่านั้น ไม่แต่งตัวเลข ไม่คาดเดาออเดอร์
- จะ **ไม่ปิดแอดหรือเปลี่ยนงบจริงโดยไม่ได้รับอนุญาต**
- คำแนะนำเป็นแนวทางประกอบการตัดสินใจ ไม่รับประกันผลลัพธ์ทางธุรกิจ
